Contributing to UGRA

Thank you for your interest in contributing to UGRA!

UGRA aims to become a modular, community-driven platform where developers can build and share useful capabilities.

Ways to Contribute

You can help by:

- Creating new skills
- Improving existing skills
- Writing automated tests
- Fixing bugs
- Improving documentation
- Suggesting new features
- Reviewing code

Skill Requirements

A new skill should:

1. Be placed in the "skills" directory.
2. Define a readable "NAME".
3. Define a short "DESCRIPTION".
4. Provide a "run(text)" function.
5. Provide a "test()" function whenever practical.

Code Quality

- Keep skills focused on one purpose.
- Use clear function and variable names.
- Include tests for expected behaviour.
- Handle invalid input safely.
- Document limitations and dependencies.
- Avoid unnecessary dependencies.

Security

- Do not expose passwords, API keys, or private information.
- Do not run destructive operations without explicit permission.
- Explain any sensitive permissions a skill requires.
- Treat contributed code as untrusted until reviewed.

Proposed Contribution Workflow

1. Discuss major changes before starting work.
2. Create a separate branch for your changes.
3. Implement the feature or fix.
4. Run the relevant tests.
5. Update documentation.
6. Submit a pull request for review.

Current Development Status

UGRA is an early prototype. Its architecture and contribution process may change as the project matures.

Contributors should clearly describe what their changes do and any known limitations.
